# QQ头像获取

AstrBot 插件：获取QQ用户头像，支持多种清晰度

## 功能

- 获取任意QQ用户的头像
- 支持6种清晰度选择
- 自动缓存头像（1小时有效期）
- 支持 @用户 或 直接输入QQ号
- 发送头像时附带图片链接

## 安装

将本仓库克隆到 AstrBot 的插件目录：

```bash
cd /path/to/astrbot/data/plugins
git clone https://github.com/landamao/astrbot-plugin-qq-avatar.git QQ头像获取
```

重启 AstrBot 即可加载插件。

## 使用方法

```
头像 @某人 [清晰度]
头像 QQ号 [清晰度]
头像              # 获取自己的头像
```

### 清晰度参数

| 参数 | 尺寸 | 说明 |
|------|------|------|
| 1 | 40×40 | 最小 |
| 2 | 40×40 | 小图 |
| 3 | 100×100 | 中等 |
| 4 | 140×140 | 标清 |
| 5 | 640×640 | 高清（默认） |
| 6 | 大头像 | 最清晰 |

### 示例

```
头像 @小明
头像 123456789 6
头像 3
```

## 配置项

在 AstrBot 管理面板的插件配置中可修改：

- `default_size`：默认清晰度等级（1-6，默认5）
